# SIMADU API — Sistem Layanan Informasi dan Pengaduan Mahasiswa

REST API berlapis berbasis **Node.js** dan **Express 5** untuk pengelolaan layanan informasi dan pengaduan mahasiswa dengan autentikasi **Bearer Token (JWT)**, otorisasi berbasis peran (**RBAC**), validasi input ketat, serta dokumentasi interaktif **OpenAPI 3.0 & Swagger UI**.
